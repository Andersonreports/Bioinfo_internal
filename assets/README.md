# Image assets

## nav-icons/
Top navigation tab icons. Most (all but `profile.png`) are cut out
(background removed) from the team's nav-bar mockup image, matching its
glossy flat-icon style. Each is a 64×64 transparent PNG. `profile.png` is
still 3D emoji from Microsoft's Fluent Emoji set
(https://github.com/microsoft/fluentui-emoji), MIT License,
Copyright (c) Microsoft Corporation.

## tool-icons/
Inhouse Tools card illustrations, cut out (background removed) from the team's
tool-card mockup image. Each is a 256×256 transparent PNG, shown at 128px on
its card in `index.html` (`.tool-card-illus`).
